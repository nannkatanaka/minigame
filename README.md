# ミニゲーム置き場

ブラウザですぐ遊べるミニゲーム集。ビルド不要、各ゲームは HTML ファイル1つで動く。

## ゲーム一覧

| フォルダ | タイトル | 内容 |
|---|---|---|
| [norakura-dakoku](norakura-dakoku/) | のらりくらり打刻 | 残業代は1時間単位。上司をかわして 19:00:00 ジャストに打刻する |
| [harapeko-hole](harapeko-hole/) | ハラペコホール | なんでも飲みこむ穴になって、机のカスから宇宙まで大きくなる |

## ゲームの追加方法

1. 半角英数字のフォルダを作り、その中に `index.html` を置く
2. ルートの `index.html` にある `<a class="game">` ブロックをコピーして、リンク先と説明を書き換える
3. 上の表に1行追加する

## 公開（GitHub Pages）

リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存すると、
`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。
